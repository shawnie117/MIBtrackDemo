एमआय बी-ट्रॅक सीआरएममध्ये आपण व्हिज्युअलाइज्ड रिपोर्ट किंवा ॲनालिसिस रिपोर्ट देखील बघू शकतो. त्यासाठी लेफ्ट साईडला Reports वरती क्लिक करून Daily Analysis Report वरती सिलेक्ट करा. Daily Analysis Report मध्ये आपण आपल्या पर्टिक्युलर Employee चा Daily Report बघू शकतो. इथे त्यांनी आज किती Leads Generate केल्या, त्यापैकी किती Leads चे Follow-Ups घेतले आहेत, त्यांचे किती Follow-Ups Pending आहेत, त्यांनी किती Tickets Resolve केल्या आहेत, त्यांनी किती Payment Collect केलं आहे, हे सर्व काही आपण Daily Analysis Report मध्ये बघू शकतो. त्यामध्ये आपण त्या Employee चा पर्टिक्युलर एका Month चा किंवा काही दिवसांचा Report देखील बघू शकतो.
